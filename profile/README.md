# BCDees Global 🌍💱

> **Peer-to-peer foreign currency exchange — safe, fast, and built for Nigerians.**

BCDees connects individuals who want to buy and sell foreign currencies (USD, GBP, CAD, EUR) using Nigerian Naira (NGN) as the settlement currency. Every trade is protected by our on-platform escrow system — NGN is locked before any FX changes hands.

---

## What We're Building

| Product | Description |
|---|---|
| 📱 **Mobile App** | Android & iOS app for end users to post ads, trade FX, and manage their NGN wallet |
| 🖥️ **Back Office** | Web-based admin panel for BCDees staff — KYC, disputes, wallet oversight, reconciliation |
| 🌐 **Public Website** | Marketing and landing site |
| ⚙️ **Backend API** | Core business logic, escrow engine, ledger, auth, and bank integrations |

---

## How the Platform Works

1. **List an ad** — Set your rate and amount. The rate is locked at creation; it never changes.
2. **Escrow kicks in** — NGN is secured on-platform before any FX moves.
3. **Trade completes** — Both parties confirm. Funds release. Zero fraud risk when the process is followed.

Supported currencies: **NGN · USD · GBP · CAD · EUR**
