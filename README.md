# Welcome to BCDees Global 👋

We're building a peer-to-peer foreign currency exchange platform — simple, safe, and community-driven.

BCDees lets people buy and sell USD, GBP, CAD, and EUR directly with each other, using Naira as the settlement currency. No middlemen, no hidden spreads. Every trade is backed by an escrow system that holds NGN securely until both parties are satisfied.

---

## What we do

If you've ever needed to send money abroad, pay an international invoice, or just swap currencies without going through a bank's painful rate, BCDees is for you. Sellers post their rates, buyers pick the best deal, and the platform holds everything in escrow so neither side can get burned.

---

## Our stack

We're a product-focused engineering team working across four codebases:

- **Mobile** — the main user-facing app, available on Android and iOS
- **Back Office** — internal admin tools for compliance, KYC, and operations
- **API** — the backend that powers everything: wallets, escrow, trades, auth
- **Web** — our public-facing marketing site

## Working here

We keep things straightforward: clear branches, conventional commits, PR reviews before anything merges. If you're joining the team, start with the `CONTRIBUTING.md` in this repo — it covers everything you need to get going.

Found a bug or have an idea? Open an issue in the relevant repo. Security concerns go straight to **security@bcdees.com** — please don't file those publicly.
