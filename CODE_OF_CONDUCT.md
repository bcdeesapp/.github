# Code of Conduct

## Our Standards

BCDees is a professional engineering organization. We expect all contributors and collaborators to:

- Be respectful and constructive in all communications
- Give and receive feedback professionally
- Focus on the work, not the person
- Protect user privacy and handle sensitive data responsibly

## Unacceptable Behaviour

- Harassment, discrimination, or personal attacks
- Leaking user data, credentials, or internal systems information
- Deliberately introducing vulnerabilities or malicious code

## Enforcement

Violations may result in removal from the organization. Report issues to **team@bcdees.com**.
